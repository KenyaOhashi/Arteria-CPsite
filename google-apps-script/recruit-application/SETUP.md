# Arteria 採用応募管理

Googleフォームに紐づけるApps Scriptです。

## 初回設定

1. Googleフォームの「︙」から「Apps Script」を開く
2. `Code.gs` を貼り付けて保存
3. `setupRecruitApplication` を実行して権限を承認

初回設定で次を自動作成します。

- 必須の「応募職種」
- 必須の「個人情報の取り扱い」同意欄
- メールアドレス・電話番号の入力チェック
- 回答スプレッドシート内の「応募者管理」「運用ガイド」タブ
- `Arteria 採用応募者ファイル` Driveフォルダ
- 応募送信時の自動処理トリガー

## 応募時の動作

- 応募者IDを発行
- 応募者ごとのDriveフォルダを作成
- 履歴書・職務経歴書を応募者フォルダへ移動して名称を統一
- 「応募者管理」タブへ応募情報と書類URLを追加
- 選考状況の初期値を「新規」に設定

既存回答を再取り込みする場合は `syncExistingResponses` を実行します。
