フォルダ構成

arteria-project-files/ ├── index.html ← トップページ ├── contact.html ← お問い合わせフォーム ├── 各ページ.html ├── assets/ │ ├── css/ ← 見た目 │ ├── js/ ← 動き │ └── images/ ← 写真・ロゴ・QRコード ├── php/ │ ├── contact.php ← フォーム送信処理 │ └── config.php ← 連携URL・通知メール設定 └── google-apps-script/ ← スプレッドシート連携コードと手順

ファイルの種類と役割

  • HTML：文章、順番、リンクを担当する「骨組み」です。
  • CSS：色、文字サイズ、余白、スマホ表示を担当する「内装・外装」です。
  • JavaScript：メニューやアニメーションを担当する「動く設備」です。
  • 画像：写真、ロゴ、QRコードです。
  • PHP：お問い合わせ内容をスプレッドシート連携へ安全に渡します。
  • Google Apps Script：受け取った内容を管理用スプレッドシートに記録します。

公開するとき

  1. PHPが使えるレンタルサーバーを用意します。
  2. このフォルダの中身を公開フォルダへすべてアップロードします。
  3. google-apps-script/SETUP.mdに沿って連携を有効化します。
  4. php/config.phpへ連携URLとAPIキーを設定します。
  5. PC・スマホ表示とお問い合わせをテストします。

重要：HTMLを直接開くだけでは送信できません。フォーム送信にはPHPサーバーとGoogleスプレッドシート連携の初期設定が必要です。
